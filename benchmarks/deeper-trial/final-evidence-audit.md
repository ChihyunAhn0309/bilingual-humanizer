# v1.5.1 공개 증거 독립 감사

평가일: 2026-10-03 KST. 공개 예정 저장소를 별도의 AI 문맥에서 읽고 실행 검증했다. 이 감사자는 실험안 작성, 상용 검사, 점수 기록에 참여하지 않았다. 같은 호스트 모델의 별도 세션 검토이며 인간 평가나 서로 다른 모델 간 검증은 아니다. 검토 대상 원본 파일은 수정하지 않았다.

**감사 범위에서 게시를 막을 만한 실질적 증거 오류를 발견하지 못했다.** 새 관측 32건의 수치·후보·원문 영수증·해시가 일치한다. 이 판정은 보관 기록의 일관성과 공개 설명의 정확성에 관한 것이다. 모든 탐지기의 Human 지표가 50을 초과한다는 목표는 달성하지 못했으며, 저자를 증명하거나 일반적인 탐지 성능을 보장하는 판정도 아니다.

출처 파일도 추가 확인했다. 기존 19개 진입 파일과 추가 16개 진입 파일은 로컬에 보존된 upstream 자료의 SHA-256과 일치했다. 추가 16개 저장소의 로컬 Git HEAD는 manifest의 commit과 같으며, 기록된 라이선스 파일의 해시도 맞는다. upstream 소스는 공개 산출물로 새로 복사하지 않았다. 이 확인은 출처 식별의 정확성을 뒷받침하며 법적 이용 허가나 각 방법의 성능을 별도로 확정하지 않는다.

## 결함, 마무리 항목과 검증 한계

수치 혼동, 다른 후보의 점수 재사용, 미검사 통과 처리, 합성 자료를 인간 자료로 표현한 부분, 50을 초과 판정한 부분은 찾지 못했다. README와 실험 보고서는 이번 변경을 좁은 의미 보존·결과 판정 수정으로 설명하며 두 실험안을 기본값으로 승격하지 않았다고 명시한다.

감사 시점에 코드 블록을 제외하고 저장소 Markdown의 로컬 링크·이미지 대상 211개를 점검했다. 없는 대상은 이 감사 파일을 가리키는 README 두 곳과 실험 보고서 한 곳뿐이었다. 이 파일을 `benchmarks/deeper-trial/final-evidence-audit.md`로 포함하면 그 3개 예정 링크가 연결된다. 외부 URL의 현재 접속 가능성이나 모든 Markdown 앵커는 검사하지 않았다.

다음은 검증 범위 밖이거나 자료 자체의 한계다.

- 영수증은 에이전트가 저장한 브라우저·도구 관측이다. 제공자가 서명한 기록이 아니며, 해시 일치는 서비스 진위나 실제 저자를 인증하지 않는다. GPTZero/QuillBot의 결과 패널만으로 입력과 결과의 관계를 독립적으로 재증명할 수 없다는 제한이 보고서에 있다.
- 입력 창에서의 확인, 유료 결제를 하지 않았다는 실행 이력, 입력 간섭 시도의 중단 여부 등은 작성자의 실행 기록과 공개 설명이다. 이 감사에서 별도 브라우저 재검사나 결제 내역 검증을 수행하지 않았다.
- 모든 시험 원문과 수정본은 합성 AI 자료다. 인간 대조군·대표성 있는 표본·반복 측정·인간 평가·다른 모델 검증이 없다. 별도 문맥 검토가 이 한계를 없애지 않는다.
- 새 입력 manifest 일부가 검사 뒤 확장되었다는 사실을 공개하고 있어 사전 등록으로 해석할 수 없다. 무료 횟수 제한으로 비교 행렬도 완전하지 않다.
- 기존 논문의 실험 수치나 현재 웹 문서 전체를 다시 감사하지 않았다. 이번 출처 감사는 목록의 개수·식별·보존된 파일·범위 표시·파생 관계의 공개 방식에 한정된다.
- 검증 스크립트는 현재 보관 자료의 일관성을 확인한다. 미래 기록의 모든 누락·새 스키마 오류를 포괄하는 형식 검증기라는 판정은 아니다. 스킬의 모든 글쓰기 결과가 의미를 보존하거나 자연스럽다는 판정도 아니다.

전체 신뢰도는 **감사한 로컬 보관 기록의 일관성에 대해 높음**이다. 외부 서비스 인증과 일반적인 탐지 성능은 이 신뢰도에 포함되지 않는다. 이 감사 파일의 예정 경로를 채우는 것 외에 공개 전에 반드시 고쳐야 할 실질적 결함은 발견하지 못했다.
