# Provenance of fresh evaluation sources

Both source texts in this directory are explicitly fictional, synthetic evaluation material created independently for this task. They do not report real events or real customer correspondence. All people, products, incidents, observations, conversations, chronological details, and technical findings were invented solely as source material for evaluating prose rewriting.

No existing candidates, methods, or reports were read. No external sources, browsing, or AI detectors were used. Neither source has been passed through a rewriting or humanizing process.

- `en-support.txt`: Original English customer support message about the fictional Foldlight desk panel. Polite professional register. Includes observed diagnostic facts, an apology, uncertainty about the cause, a conditional replacement remedy, and a promised progress-report deadline. Count: **240 whitespace-separated words**, including greeting and sign-off.
- `ko-essay.txt`: Original Korean personal essay narrated by a fictional reading-group participant. First-person general-audience prose, mixed feelings, a modest change of mind, and specific chronological details. Count: **239 whitespace-separated eojeol**.

Counts use trimmed text split on one or more whitespace characters. Paragraph breaks count as whitespace separators. The fiction label is kept in this provenance file rather than embedded in either source text so later rewriting can operate on the intended genre alone.

The invented factual and experiential content is fixed input for later evaluation; a later rewriter should preserve it rather than invent additional evidence.
