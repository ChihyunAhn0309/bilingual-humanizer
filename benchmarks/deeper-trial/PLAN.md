# Generalization experiment, 2026-10-03 KST

User target: each tested detector's native human indicator above 50, plus independent verification and GitHub publication. This is a local acceptance target, not a guarantee over every detector, document, or future model. Native metrics are not interchangeable authorship probabilities.

Frozen production baseline: v1.5.0. Test two distinct instruction prototypes: discourse/working prose (A), and contrastive clause editing with original synthetic examples (B). No paid service or downloaded model execution.

Development sources: prior fresh museum memo (English), equipment proposal (Korean), and library policy memo (Korean). These are now development data, not held-out data. Writers receive only their method and original sources. Independent review occurs before commercial scans and checks preservation, genre fit and prose quality. Record every scan, including failures, exact submitted text hash, model version and actual observation time. Human scores must be strictly greater than 50. For detectors showing only AI scores, do not relabel 100-AI as a vendor-issued Human probability.

Select only faithful candidates. Test both methods first on museum/equipment; use library as an additional development case. If a candidate improves broadly, freeze the reusable instructions before a fresh English and Korean evaluation. Do not promote development winners alone as proof of generalization. If neither method meets the goal, retain production rewriting and report the unmet target; improve evidence/reporting guidance where the findings support a concrete correction.

Free quotas constrain the sequence. Prioritize paired GPTZero and QuillBot tests on the same exact files, with Sapling for English and ZeroGPT for Korean as additional checks. Support/calibration limitations must remain visible. Independent final audit verifies the repository artifacts and claims before publication.
