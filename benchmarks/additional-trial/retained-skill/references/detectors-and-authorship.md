# AI 탐지기와 작성 이력 해석

확인일: 2026-10-02. 공개 제품 문서와 논문을 비교한 자료다. 업체 설명은 그 업체가 공개한 주장이라는 뜻이며, 독립적으로 재현한 성능을 뜻하지 않는다. 현재 서비스 11개와 중단된 비교 사례 1개를 다룬다. 모든 탐지기를 망라하거나 비공개 모델을 역설계한 자료는 아니다.

## 무엇을 판별하는가

텍스트 분류기는 학습한 분포와 문체 특징을 바탕으로 작성 방식을 추정한다. 실제 작성 과정을 관찰하지 않은 결과로 작성자를 확정할 수는 없다. 점수가 낮아져도 AI 초안의 생성 이력이 바뀌지 않는다. Turnitin도 오판 가능성을 밝히며 불이익 조치의 유일한 근거로 쓰지 말라고 안내한다. [Turnitin 사용 안내](https://guides.turnitin.com/hc/en-us/articles/22774058814093-Using-the-AI-Writing-Report)

다음은 서로 다른 항목이다.

- **자연스러움:** 독자가 문장과 문단을 어떻게 읽는가.
- **내용 충실도:** 원문 정보·입장·제약이 유지되는가.
- **탐지 결과:** 특정 버전의 모델이 특정 입력을 어떻게 분류했는가.
- **작성 이력:** 누가 어떤 도구로 초안을 만들고 어떻게 수정했는가.
- **표절 여부:** 다른 출처와 어떤 내용이 겹치며 인용이 적절한가.

이 구분은 본 스킬의 설계 원칙이다. 서로 다른 업체의 백분율을 같은 확률로 평균하거나, 하나의 점수로 나머지를 대체하지 않는다.

GPT킬러 매뉴얼은 문서에서 문장을 추출한 뒤 길이·단락을 고려해 검사 구간을 구성하고, 구간별 결과를 어절 수에 기초해 취합한다고 설명한다. 2,000자를 약 400자씩 나누는 내용은 예시이며 고정 규격으로 단정하지 않는다. 같은 매뉴얼은 표절검사를 함께 선택했을 때 결과가 합산될 수 있다고 설명하므로, 실제 보고서의 검사 설정과 항목 정의를 먼저 확인해야 한다. 업체가 제시한 정확도 표는 이 스킬이 실측한 결과가 아니다. | 생성 시 워터마크 | 생성 단계에서 특정 토큰 집합을 통계적으로 선호하게 하고 검정한다. [논문](https://arxiv.org/abs/2301.10226) | 일반 문체 분류와 다르다. 모든 LLM 출력에 같은 워터마크가 있다는 증거는 아니다. |
| 비원어민 영어 연구 | 2023년 연구의 특정 탐지기·표본에서 비원어민 글의 오탐 편향을 보고했다. [논문](https://arxiv.org/abs/2304.02819) | 단순하거나 예측 가능한 영어를 AI의 증거로 취급하지 않는다. 당시 오류율을 현행 모든 제품에 적용하지 않는다. |

KatFishNet의 **94.88**은 논문 표 3에서 에세이에 대한 punctuation 모델의 평균 AUROC를 0~100 척도로 표시한 값이다. 시와 논문 초록의 같은 행 평균은 각각 73.10, 75.62다. 따라서 94.88%를 모든 한국어 글에 대한 정확도, 쉼표 하나의 판별력, 또는 humanizer의 성공률이라고 부를 수 없다. [논문 PDF 8쪽 표 3](https://aclanthology.org/2025.acl-long.1030.pdf)

AUROC는 임계값 전반의 구분 능력이고, accuracy는 선택한 임계값에서 맞힌 비율이다. 어느 것도 개별 문서의 작성 이력을 증명하는 수치는 아니다. 이 정의와 위 구분은 성능 표를 읽기 위한 해석 원칙이다.

## 결과를 받은 경우

먼저 탐지기 이름, 검사 시각, 모델/플랜(알 수 있는 경우), 입력 언어·분량, 전체 문서 여부, 점수 정의와 하이라이트를 확인한다. 결과가 없는 상태에서 점수나 통과 사실을 만들어 내지 않는다. 미지원 언어·짧은 글·혼합 언어·표 중심 문서는 검증 범위를 벗어날 수 있다고 해당 조건만 구체적으로 설명한다.

사용자가 탐지 결과를 반영한 반복 편집을 요청하면 [반복 검토 절차](iterative-review.md)를 따른다. 표시된 문장은 원문과 대조해 자연스럽고 충실한 대안을 검토하되, 점수만을 이유로 정확한 전문용어·조건·근거를 없애지 않는다. 비교 시험은 동일한 설정을 사용하고 실패·오류·무응답도 기록한다. 모든 목표 탐지기의 결과가 같은 최종본을 검사했을 때만 그 최종본의 목표 충족 여부를 말한다. 외부 전송은 사용자가 지정하거나 승인한 문서와 서비스 범위 안에서만 한다. 이 패키지에는 자동 업로드나 유료 API 호출 기능이 없다.

작성 이력을 설명해야 한다면 실제 존재하는 연구 메모, 출처, 초안, 버전 이력, 본인의 기여 설명을 정리한다. 생성 후 만든 해시는 파일의 동일성을 확인할 뿐 과거 작성 시점이나 인간 저자를 입증하지 않는다. AI가 작성한 초안을 다듬었다면 그 사실과 사람의 실제 기여를 구분한다. 기록이 없으면 없다고 쓴다.

허용되는 결과 문구의 예: `제공된 결과에서 이 버전의 탐지기는 해당 글을 낮은 AI 가능성으로 분류했습니다. 이는 작성자를 확정하는 증거는 아닙니다.` 실제 결과가 있을 때만 쓴다. `100% 사람이 작성했음을 인증합니다` 같은 확인할 수 없는 인증 문구는 만들지 않는다.
