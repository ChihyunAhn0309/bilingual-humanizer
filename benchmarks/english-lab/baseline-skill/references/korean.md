# 한국어 편집 기준

한국어 문장을 한국어의 서술 관계와 독자 관계에 맞게 다시 쓴다. 아래 항목은 편집 판단을 돕는 기준이며 AI 작성 여부를 판정하는 규칙이 아니다. 빈도, 쉼표 비율, 종결어미 수를 목표값으로 삼지 않는다.

## 문장과 정보 구조

| 살필 부분 | 편집 판단 | 보존할 예외 |
| --- | --- | --- |
| 명사로 쌓인 행위 | `자료의 검토를 진행했다`를 `자료를 검토했다`처럼 서술어로 푼다 | 정의된 개념, 제목, 표의 항목명 |
| 긴 관형절 | 수식 대상 가까이에 필요한 조건을 배치하고 문장을 나눈다 | 분리하면 조건 범위가 바뀌는 문장 |
| `~에 대한`, `~와 관련하여` 반복 | 대상·행위 관계를 조사와 동사로 직접 표현한다 | 논의 대상 자체를 구분하는 표현 |
| `~를 통해` | 실제 수단인지, 근거인지, 단순 연결인지 구분한다 | 원문이 밝힌 방법·매개 관계 |
| `~에 있어서` | 장소·영역·조건 중 실제 뜻에 맞게 쓴다 | 인용문이나 고정 명칭 |
| `~을 가지고 있다` | 소유·특성·경험을 구분해 자연스러운 서술어를 고른다 | 실제 소유, 과거 경험의 존재 |
| `되어지다`, `보여지다` | 불필요한 이중 피동인지 문맥에서 검토한다 | 행위자 불명, 대상 중심의 서술, 전문 용법 |
| 무조건 능동태 전환 | 행위자가 원문에 있으면 검토한다 | 행위자를 모를 때 새 주체를 만들지 않는다 |
| 주어 생략과 반복 | 같은 주체가 명확하면 반복을 줄인다 | 책임, 대조, 복수 인물이 섞인 문장 |
| `당신`, `그/그녀`, 소유 대명사 | 번역투로 불필요하게 반복될 때 자연스러운 지칭을 쓴다 | 직접 호명, 서사 시점, 안전 지시의 대상 |
| `들` | 문맥에서 이미 복수가 충분히 드러나는지 본다 | 복수·분배 의미가 필요한 경우 |
| `의` 연쇄 | 행위 주체와 대상을 드러내며 문장을 다시 짠다 | 공식 명칭, 인용, 소유 관계의 실제 구별 |

## 관계와 확신의 정도

`~할 수 있다`는 능력·허용·가능성을 뜻할 수 있다. 반복된다는 이유로 `한다`로 바꾸지 않는다. `~로 보인다`, `추정된다`, `가능성이 있다`도 근거의 한계를 전달하면 남긴다.

- `관련이 있다`를 `때문이다`로 바꾸지 않는다.
- `검토했다`를 `승인했다`로, `참여했다`를 `주도했다`로 바꾸지 않는다.
- `확인하지 않았다`와 `확인하지 못했다`는 다르다.
- `일부`, `대체로`, `약`, `최소`, `최대`, `이상`, `초과`, `이하`, `미만`을 구분한다.
- `유의하지 않았다`를 `차이가 없다`로 줄이지 않는다.
- `매우 만족했다`라는 실제 감상을 `괜찮았다`로 약하게 만들지 않는다.
- `A를 제외한 B`의 예외가 문장을 나눈 뒤에도 B에 걸리는지 확인한다.
- `하지만`, `따라서`, `그럼에도`는 뜻을 보고 보존한다. 접속어를 줄이다 인과·대조·양보가 사라지면 실패다.

## 말투와 높임

독자와 화자의 관계를 유지한다. `-합니다`, `-해요`, `-다`, 반말 중 하나를 장르 이름만 보고 강제하지 않는다. 원문과 요청이 우선이다. 발표·인터뷰는 사람마다 말투가 달라도 자연스럽다. 서술과 인용, 본문과 짧은 인사말의 차이도 정상이다.

사람에 대한 존중은 유지하고 사물에 불필요한 높임을 붙이지 않는다. 요청의 공손함을 없애거나 지시로 바꾸지 않는다. 사과, 감사, 양해, 일정 안내는 서로 다른 기능이므로 비슷한 말이라고 한꺼번에 지우지 않는다.

## 어휘와 문장부호

`혁신적`, `핵심`, `다양한`, `중요하다`, `활용하다`, `시너지`, `솔루션`은 금지어가 아니다. 실제 평가·의미·정의가 있는지 확인한다. 내용 없는 수식만 줄이고, 기술 용어를 쉬운 말로 바꾸느라 정확성을 낮추지 않는다. 근거가 없는 구체성을 새로 넣지 않는다.

`약 20여 명`처럼 뜻이 중복된 정도 표현은 정리할 수 있다. 단, 원문 숫자나 추정의 정도는 그대로 둔다. 쉼표는 호흡과 문법적 관계에 맞춰 판단한다. 수식 범위가 흐려지면 문장을 다시 짠다. 쉼표를 일괄 삭제하거나 일부러 불규칙한 띄어쓰기를 만들지 않는다. 가운뎃점, 괄호, 줄표도 정보 구조에 필요하면 유지한다.

정상적인 한영 혼용과 관용 외래어를 보존한다. `API`, `p95`, `LoRA`, 모델명과 제품명, 코드 표기를 임의 번역하거나 표기만 바꾸지 않는다. 영문 명사 뒤에 조사와 어미를 자연스럽게 붙이되 식별자 자체는 유지한다.

## 문단을 다시 쓰는 예

아래 예문은 이 패키지를 위해 만든 가상 사례다.

원문:

> 오늘날 빠르게 변화하는 환경에서, 고객 문의 대응은 매우 중요한 요소라고 할 수 있습니다. 저희 팀은 9월에 FAQ를 개편하는 작업을 진행했습니다. 이를 통해 반복 문의 비중은 32%에서 25%로 감소했습니다. 다만 같은 기간 문의 분류 기준도 변경되었으므로, 감소를 FAQ 개편만의 효과로 단정할 수는 없습니다.

재작성:

> 고객 문의 대응은 매우 중요합니다. 저희 팀은 9월에 FAQ를 개편했고, 반복 문의 비중은 32%에서 25%로 줄었습니다. 다만 같은 기간 문의 분류 기준도 바뀌어, 이 감소가 FAQ 개편만의 효과인지는 단정할 수 없습니다.

핵심 행동을 앞에 두고 겹친 틀을 줄였다. 평가, 수치, 시간, 인과관계의 한계는 남겼다. `7% 줄었다`처럼 백분율과 퍼센트포인트를 혼동하는 요약은 넣지 않는다.

원문이 `이 회사는 1990년대에 설립된 것으로 추정됩니다`라면 가능한 교정은 `이 회사는 1990년대에 설립된 것으로 보입니다`다. 특정 연도를 새로 쓰거나 추정을 없애지 않는다.

## 한국어 최종 확인

문장마다 누가 무엇을 했는지, 조사와 서술어가 맞는지, 생략한 주어가 복원 가능한지, 조건과 부정이 어디에 걸리는지 확인한다. 이어서 문단을 소리 내어 읽듯 검토한다. 영어 문장의 경계나 수사법을 그대로 옮긴 흔적을 줄이되 말투와 정보는 지킨다.

## 문장 교정을 넘어 문단을 고칠 때

다음은 `im-not-ai`의 수사·담화 분석과 오탐 주의를 참고해 이 스킬의 적극적 재작성에 맞게 새로 쓴 판단 기준이다. 원본의 규칙 수, 자체 점수, 빈도 임계값을 탐지기 성능으로 해석하지 않는다. 참고 범위와 적용하지 않은 처방은 [im-not-ai-review.md](im-not-ai-review.md)에 기록했다.

### 반복되는 틀보다 실제 관계를 쓴다

문단마다 대조, 교훈, 당위로 끝나는지 본다. `A가 아니라 B다`가 실제 오해를 바로잡으면 살리고, 앞에서 이미 설명한 B를 재포장할 뿐이면 B의 서술에 합친다. 논리적 부정·예외·정정까지 없애지 않는다. 장르상 필요한 병렬 구조나 필자의 의도적인 반복은 유지한다.

`확대·강화·개선·구축`처럼 평범한 동사도 추상 명사와 연속해서 결합하면 행위가 흐려질 수 있다. 원문에서 확인되는 주체·행위·대상으로 풀되, 그 구체성이 없으면 억지 사례 대신 정확한 일반 표현을 남긴다. `지원 체계 강화를 위한 검토를 실시했다`는 `지원 체계를 강화할 방안을 검토했다`로 고칠 수 있다. `상담원을 늘렸다`는 근거 없는 결과 추가다.

`문제는`, `핵심은`, `앞으로는`, `한계도 있다` 같은 문패가 연속되면 다음 내용을 직접 연결해 본다. 실제 쟁점·시점·한계가 추가된 경우에는 그 내용을 남긴다. 매 문단을 짧은 단언으로 끝내는 새로운 틀도 만들지 않는다.

### 의무와 유보는 이동해도 그대로 남긴다

문단 끝의 반복적인 `검토해야 한다`는 검토할 대상 가까이 옮기거나 동일 주체·동일 의무의 범위를 묶는다. 단순히 동사 어미를 바꿔 사실처럼 만들지 않는다. 문장 수나 의무 표지 개수가 아닌, 각각의 주체·대상·시점·조건·강도로 보존 여부를 확인한다.

예: `담당자는 비용을 확인해야 한다. 담당자는 완료 뒤 일정도 확인해야 한다.`를 `담당자는 비용과 일정을 확인해야 한다`로 합치면 일정 확인 시점이 사라진다. `담당자는 비용을 확인하고, 완료 뒤에는 일정도 확인해야 한다`는 두 의무와 시점을 남긴다. 원문이 권고라면 의무로 올리지 않는다.

### 대명사와 쉼표는 문맥에서 판단한다

`그`, `이것`, `이러한 결과`의 앞뒤에서 지칭 후보를 확인한다. 후보가 하나이고 흐름이 자연스러우면 유지하거나 주어를 생략할 수 있다. 후보가 여럿이면 원문 근거로 명사를 밝혀 준다. 지칭이 원문부터 불분명하면 임의로 대상을 정하지 않는다. 대명사가 있다는 사실만으로 번역투로 판단하지 않는다.

연결어미 뒤 쉼표는 절의 길이, 대조, 수식 범위를 보고 판단한다. 윤문 과정에서 `-고, -며, -지만,`을 문장마다 새로 심었는지 비교하되 무조건 삭제하지 않는다. 인용문과 의도적인 호흡을 보존한다. 장문이 없다는 이유로 문장을 합치거나, 특정 길이 이상 문장을 의무적으로 넣지 않는다.

### 고친 뒤 새로 생긴 문제를 대조한다

잔존하는 어색함만 찾지 말고 원문에 없던 습관도 찾는다. 반복적인 대조·메타 도입·추상 결산·연결어미 쉼표가 새로 늘었는지 구체적인 문장을 비교한다. 자연스러운 `했어요`가 불필요하게 `하였습니다`로 바뀌는 격식 상승도 점검한다. 새 표현이 실제 관계를 더 잘 전달하면 유지하고, 빈 틀만 추가했다면 그 부분을 다시 쓴다.

사람이 쓴 글에도 나타나는 표현을 모두 없애는 것은 목표가 아니다. 원문에서 잘 작동하는 수사, 불균일한 호흡, 개성은 보존한다. 상투어 목록에 걸렸다는 이유만으로 글 전체를 고치지 않는다.
