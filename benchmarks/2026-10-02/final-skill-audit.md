# bilingual-humanizer v1.4.0 독립 패키지 감사

- 감사일: 2026-10-02
- 대상: `outputs/bilingual-humanizer`, `SKILL.md`의 버전 `1.4.0`
- 방법: 독립 컨텍스트에서 패키지 본문, 모든 참조문서, Python 코드, 예문 및 단위검사를 검토했다. 앞선 감사 보고서와 실제 detector 점수는 읽지 않았다. 상용 서비스, 외부 웹, 계정 또는 API에 접근하지 않았다.
- 변경 범위: 감사자는 패키지를 수정하지 않았다. 이 보고서만 작성했다. 감사 중 작성자가 알려온 수정은 해당 파일을 다시 읽어 별도 확인했다.

## 결론

최초 검토에서 의미 보존 원칙과 충돌하는 예시 1건(P2)을 발견했다. 작성자가 이를 수정했고, 같은 감사자가 후속 확인한 결과 해당 문제가 해결되었다. **후속 확인 시점의 미해결 actionable finding은 없다.** 이는 같은 모델의 독립 컨텍스트 검토와 후속 검토 결과이며, 독립 인간 평가나 여러 모델의 평가가 아니다.

검토한 범위에서는 한국어·영어·혼합 문서 지원, 문장·문단의 적극적 재작성, 불변 원문과 대조하는 반복 검토, 사실·의미 보존, 실제 detector 결과의 제한된 해석이 서로 일관된다. 자연스러움이나 탐지 통과 성능이 우월하다는 결론은 이 감사로 내리지 않았다.

## 최초 발견 및 후속 수정 확인

### [P2, 수정 확인] 조건부 운영 변경을 확정된 일정으로 바꾸는 한국어 예시

- 위치: `references/structural-rewrite.md:96`
- 최초 원문: `공간의 수용 인원은 8명이다. 운영 시간을 늘려도 정원은 달라지지 않는다. 안내에서는 시간과 정원을 구분해 설명해야 한다.`
- 최초 권장 재작성: `안내에는 늘어나는 운영 시간과 그대로인 정원 8명을 구분해 밝혀야 한다.`
- 문제: 원문의 `운영 시간을 늘려도`는 연장하더라도 정원이 그대로라는 조건 관계다. `늘어나는 운영 시간`은 운영 시간이 실제로 늘어난다는 전제를 추가한다. 연장이 아직 가정인 문서에서는 계획·상태가 바뀐다. 이는 `SKILL.md:34`의 조건·시점·양태 보존 원칙과 충돌하며, 적극 재작성의 본보기로 제시되어 있어 수정할 가치가 있다.
- 전달한 수정 방향: 조건부 관계를 유지하고 운영 연장의 확정 여부를 추가하지 않는다.
- 후속 확인한 재작성: `운영 시간을 늘리더라도 정원은 8명으로 같다. 안내에서는 운영 시간과 이 정원을 구분해 설명해야 한다.`
- 추가된 지침: `조건부 연장을 이미 확정된 운영 변경으로 바꾸지 않는다.`
- 판정: 조건·정원 수치·안내 의무가 보존되므로 최초 발견사항은 해결되었다. 이 확인은 최초와 독립된 새 블라인드 감사가 아니라 기존 감사자의 후속 검토다.

## 다른 검토 항목

- **지침 충돌과 불필요한 제약:** 기본 구조 재작성은 사용자 요청 범위, 원문 의미, 인용 및 정의된 용어에 종속된다. 특정 변경률, 문장 길이 분포, 어미 수, 쉼표 수, 대시 금지 등을 보편 조건으로 강제하지 않는다. 기본 반복 한도는 존재하지만 사용자 지정 한도와 필수 충실도 복구를 별도로 다루므로 이를 결함으로 판단하지 않았다.
- **실제 detector 결과:** 제품별 점수의 정의와 단위를 구분하고, 같은 최종 후보의 해시·설정·범위·증빙을 확인하도록 요구한다. 미지원, 오류, 누락, 반올림된 0을 성공으로 처리하지 않는다. 오프라인 결과 검사기가 실제 서비스를 호출하거나 증빙을 인증하지 않는다는 제한도 명시되어 있다. 검토한 코드에서 이 계약에 반하는 재현 가능한 오류는 발견하지 못했다.
- **보존 검사기:** 표면 특징을 비교하는 도구로 범위를 한정하며, 수치의 지시 대상 교환이나 부정·의미 변화는 통과할 수 있음을 지침과 검사 양쪽에 명시한다. 이 제한을 실제 의미 보존 검증으로 오인하도록 안내하지 않는다.
- **미검증 성능 주장:** 로컬 코드 검사, 합성 예문, 편집 판단, 독립 검토, 상용 detector 실측을 분리한다. AUROC와 정확도, 탐지 결과와 작성 이력도 구분한다. 패키지 자체의 범용 자연스러움·탐지 성공률을 실증한 것처럼 주장하는 구절은 발견하지 못했다.
- **im-not-ai 반영:** `references/im-not-ai-review.md:3-20`과 `references/skill-sources.json:122-157`은 커밋, 검토한 파일 해시, 채택·제외한 처방을 기록한다. 실제 지침에도 담화 단위 재작성, 새 상투구·격식 상승·쉼표 습관 검토가 반영되어 있다. 고정 변경률이나 자체 실험 결과를 이 스킬의 탐지 성능으로 옮기지 않는다.
- **출처와 라이선스:** 상류 저장소의 커밋·경로·해시·라이선스 정보를 남기고, 라이선스 API의 `NOASSERTION`을 부재 확정으로 해석하지 않는다. 검토한 패키지에서 상류 코드 전체나 실험 자료를 묶어 재배포한다는 증거는 발견하지 못했다. 다만 원본 상류 파일과의 직접 대조 및 라이선스 의무의 법적 판단은 하지 않았다. 따라서 무단 복제가 없다는 인증이나 라이선스 준수 확정은 아니다.

## 실행한 로컬 검사

1. 포함된 단위검사 42개 중 파일을 쓰지 않는 37개를 `python -B`로 실행: **37개 모두 통과**.
2. 임시 파일 작성·하드링크를 수반하는 CLI 검사 5개는 read-only 범위를 유지하기 위해 실행하지 않음. 해당 코드와 검사 본문은 읽었다.
3. 모든 `.py` 파일을 메모리에서 `compile()`로 파싱: 성공. 바이트코드 파일은 쓰지 않았다.
4. 모든 `.json` 파일 파싱: 성공.
5. Markdown의 상대 링크 대상 존재 여부: 누락 없음.

단위검사는 합성 fixture를 사용하며, 실제 detector를 실행하지 않는다. 이 결과는 보존 검사기와 결과 일관성 검사기의 동작에 관한 제한된 근거이고, 스킬을 사용하는 언어모델의 자연스러움이나 의미 보존율을 측정하지 않는다.
