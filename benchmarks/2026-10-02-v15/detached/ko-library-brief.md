# 분리 작성용 의미 메모: 도서관 저녁 개관 시범안

## 판단 대상과 경계

- D1 — 지역 도서관의 제안: **6주**, **화요일·목요일**, 저녁 개관 종료 **20:00**. 시행이 끝난 실적이나 확정된 상시 일정으로 쓰지 않기.
- D2 — 기간을 한정한 시범안. 영구 정책 확정 상태 아님. 저녁 연장 시범 논의와 앞으로의 상시 개관 시간 논의를 구별할 필요.
- D3 — 이용자 안내에서도 한시성/상시성 구별을 명확히 전달. 이후 문서 표현 검토에서도 시범 결정이 영구 일정 변경까지 결정한 것으로 읽히는지 확인.
- D4 — 이후 판단: 연장 개관에 관심이 있다는 점 인정 + 해당 시간의 자원봉사 참여 가능 여부 확인. 관심만으로 운영 조건이 충족된 것은 아님.

## 실행 가능성과 실제 제공 범위

- O1 — 해당 저녁 시간에 자원봉사자가 참여할 수 있는지 **미해결**. 저녁 운영 가능성 판단에 필요한 조건. 운영 개시 후 처리할 사소한 항목으로 미루기 어려움. 부족이 확인되었다거나 봉사자가 전혀 없다는 뜻 아님.
- O2 — **조용한 열람실 정원 12명**. 도서관 전체 정원으로 넓히지 않기. 개관 시간 연장으로 이 공간의 정원이 늘어나지는 않음.
- O3 — 이용 안내 작성자: 도서관 이용 가능 시간과 조용한 열람실의 **동시 수용 인원**을 각각 설명할 필요. 시범안의 제공 범위를 판단할 때에도 시간·공간 수용력 두 조건을 함께 고려.

## 의견이 보여 주는 것

- E1 — 접수된 **의견서 총 42건**: 연장 개관 지지 **28건**; 현재 일정 선호 **9건**; 선호안 없음 **5건**. 단위는 의견서/건; 사람 수나 전체 이용자 조사로 바꾸지 않기. 선호안 없음을 반대·무응답·기권으로 바꾸지 않기.
- E2 — 집계의 의미: 제출된 의견 안에서의 선택 분포. 도서관 이용자 모두의 요구를 그대로 대표한다고 볼 수 없음.
- E3 — 검토자: 연장 지지 의견을 살피면서 현행 일정 선호도 함께 고려해야 함. 다수 지지의 삭제나 소수 의견의 배제 모두 피하기.
- E4 — 응답 수만으로 각 선택의 이유까지 파악할 수 있다고 가정하지 않기. 동기·사연·시간대별 수요 등 추가 정보 없음.
- E5 — 현재 자료: 연장 개관이 방문 증가를 **일으킨다는 인과적 근거 없음**. 지지는 선호의 표시이며 실제 방문으로 연결되었다는 증거와 구별. 방문이 늘지 않는다고 입증된 것도 아님.
- E6 — 검토자가 위 한계를 유지하면 응답을 과장해 해석하지 않고 운영안을 논의할 수 있음. 자료의 쓰임을 전면 부정하는 결론은 아님.

## 요청·권고의 대상과 강도

- R1 — 운영안 검토자/판단자 → 시범과 상시 운영 논의를 구별; 다음 결정과 문서 작성 때 지속 적용할 필요.
- R2 — 이용 안내 담당자 → 한시 운영이라는 점 명확히 전달; 이용 시간과 열람실 동시 정원도 각각 설명할 필요.
- R3 — 의견 검토자 → 현행 일정 선호 의견도 고려; 대표성·이유·방문 효과를 응답 수에서 임의로 추정하지 않기.
- R4 — 운영 판단자 → 시작 전에 검토해야 할 실행 조건으로 봉사자 참여 가능 여부 확인. 이미 확정된 의무 절차·승인 체계나 특정 담당자 이름을 만들지 않기.
- R5 — 시범 제공 범위 검토자 → 시간 연장과 공간 정원을 함께 판단.
- R6 — 이후 판단자/문서 작성자 → 관심은 인정하고 봉사 참여 가능성을 확인하며 영구 변경으로 오독될 표현을 점검할 필요. 시행 명령이나 취소 결정 아님.

## 반복의 통합 범위

- 한시성은 세 가지 역할: 제안의 상태 설명, 논의·안내의 구분 지침, 후속 문서 오독 방지. 한곳으로 합쳐도 상태·안내·문서 검토 기능을 모두 남기기.
- 봉사자 조건은 현재 미해결 사실, 시행 전 판단에 필요한 이유, 이후 확인 요청으로 반복. 단순히 “검토할 문제”라고만 줄이면 강도가 사라짐.
- 시간과 정원은 실제 제약 설명, 이용 안내 항목, 제공 범위 판단 기준으로 반복. 수치와 세 기능 유지.
- 의견의 한계는 대표성·이유 추론·인과성/실제 방문이라는 서로 다른 문제. 하나의 막연한 유보문으로 합치지 않기.
- 지지 의견의 존재는 수치 보고, 현행 일정 선호와 함께 고려하라는 요청, 이후 판단에서 관심을 인정하라는 요청으로 이어짐.

## 문체 및 문서 소개 문장의 처리

- 차분한 공공 운영 검토문, 설명형 평서체. 숫자와 운영 조건 중심. 시범안을 홍보하거나 비난하는 목소리, 개인 경험, 임의 사례 없음.
- 실제 판단: 한시/상시 구분 필요; 현행 일정 선호도 고려; 봉사자 조건을 운영 후로 미루기 어려움; 시간과 정원은 별개; 의견을 방문 효과로 확대 해석하면 안 됨.
- “검토에서 의견과 확인 조건을 다룬다”는 내용은 문서 자신의 작업을 소개하는 말. 독립 문장으로 재현할 필요 없음. 운영안을 구체화하기 전이라는 검토 단계는 유지 가능.
- 한시안·영구 정책 미확정·봉사자 참여 미해결은 단순한 문서 소개가 아니라 실제 제안의 상태이므로 반드시 유지.
- 원문의 문단 배열을 따를 필요 없음. 결정의 범위 → 실행 조건 → 의견의 증거와 한계 등 독자 판단에 맞춰 구성 가능.
