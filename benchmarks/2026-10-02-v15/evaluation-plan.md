# v1.5 prospective comparison plan

Recorded 2026-10-02 before any v1.5 detector request. Skill behavior files are frozen before the forward writer runs; source research/packaging notes may still be completed. No detector scores are given to the candidate writers or fidelity/readability reviewer.

- Development set: four previously used EN/KO library/cache memos. Scores have informed the project, so this set is adaptive development, never a held-out performance claim.
- Prospective set: two fresh synthetic sources generated in a separate context without skill/corpus/scores: English practical newsletter and Korean personal informative essay. They are AI-produced, not human controls. Root has not read their contents before skill freeze.
- Same two source files are independently rewritten with frozen v1.4 and v1.5. Each writer sees the source and its assigned skill only; no scores, other version or competing draft.
- A fresh reviewer receives original + randomly labeled candidates without version labels or detector scores. It checks information/voice preservation and identifies concrete reader-quality differences. This is same-family model review, not human/cross-model judgment. Candidates may be corrected for specific fidelity defects before detector testing; record every correction.
- Planned commercial requests: Sapling all four new English candidates (two development + paired holdout), ZeroGPT all four new Korean candidates (two development + paired holdout); GPTZero paired English holdout within 504 visible remaining credits; QuillBot paired Korean holdout and one Korean development candidate within three visible free scans. Re-evaluate access if actual text length prevents this allocation. Do not pay or bypass a quota. Record blocked/missing rather than substituting a favorable text.
- Input is complete text, no excerpting to improve score. Verify vendor language/length eligibility, exact normalized input and fresh result. Capture hash, time, model/metric and receipt. Commercial scores remain in their native units; no cross-vendor averaging or invented common authorship percentage.
- Success interpretation: report each paired delta and vendor classification, including unchanged/worse scores. More favorable classification on a few cases cannot establish general performance. A candidate that loses meaning is not a successful rewrite whatever its score.
- No post-score revision of the prospective candidates in this comparison. Any later skill changes require a separately labeled development round and new heldout material. The experiment cannot test stochastic run-to-run variance, independent native-reader preference, human-control false positives or broad genre coverage.
