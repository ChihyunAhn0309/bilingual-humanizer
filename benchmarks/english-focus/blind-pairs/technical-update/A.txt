The queue test compared the existing worker with the proposed worker on 12 jobs. Ten jobs completed in both configurations. For those ten jobs, median processing time fell from 75 ms to 52 ms with the proposed worker. Two other jobs failed before producing a timing result and were excluded from that comparison. We have not established what caused those failures.

The proposed worker kept the retry limit at 3 and used more memory in this test. Peak memory was not recorded, so we cannot quantify the largest increase or use these results to predict peak usage in production.

The test did not include concurrent clients. I would like to repeat it with concurrent clients before recommending a rollout. That repeat has not been scheduled, and no production change has been approved.

The review note must state both the ten-job denominator for the timing comparison and the two excluded failures. Before approving a rollout, the service owner should review the memory measurements from the repeat test.
